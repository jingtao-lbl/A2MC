# div-grad Operator (`divgrad/`)

The `divgrad/` subdirectory contains `MatrixMFD` and the surface-coupled extension `MatrixMFD_Coupled_Surf`. These classes implement the discrete divergence-gradient (Laplacian-type) operator using mimetic finite differences (MFD), and form the elliptic/parabolic core for Richards equation, overland flow, and the coupled subsurface-surface flow system.

## Source files

| File | Lines | Role |
|---|---|---|
| `divgrad/MatrixMFD.cc` | 1128 | Core MFD operator assembly, apply, inverse, Schur complement |
| `divgrad/MatrixMFD_Coupled_Surf.cc` | 487 | Extension for coupled subsurface-surface block system |

No ATS-side header files exist for these classes in `src/operators/divgrad/`; the headers (`MatrixMFD.hh`, `MatrixMFD_Coupled_Surf.hh`, and many related specializations) live in Amanzi. The `.cc` files include `"MatrixMFD.hh"` and `"MatrixMFD_Coupled_Surf.hh"` from the Amanzi include path.

## Mathematical structure

MFD represents the solution on two entity types simultaneously. For a 3D prismatic mesh:

- **Cell unknowns** (pressure `p_c`, temperature, etc.) live at cell centroids.
- **Face unknowns** (Lagrange multiplier `lambda_f`, representing the trace of the potential on faces) live at face centroids.

The assembled system for one block has the saddle-point structure:

```
[ Aff   Afc ] [ lambda_f ]   [ Ff ]
[ Acf   Acc ] [   p_c    ] = [ Fc ]
```

where `Aff` is face-face (nfaces x nfaces per cell), `Acf`/`Afc` are off-diagonal coupling blocks, and `Acc` is a scalar diagonal (row sum). These elemental matrices are stored as per-cell dense objects before assembly into global sparse matrices.

## MFD method variants

`MatrixMFD::InitializeFromPList_()` reads the `"MFD method"` parameter and selects one of nine discretization strategies via the `MFD3DMethod` enum (`src/operators/divgrad/MatrixMFD.cc:81`):

| Input string | Enum | Description |
|---|---|---|
| `"mfd"` | `MFD3D_POLYHEDRA` | Basic MFD, general polyhedra |
| `"mfd scaled"` | `MFD3D_POLYHEDRA_SCALED` | Scaled inverse mass matrix |
| `"monotone mfd"` | `MFD3D_POLYHEDRA_MONOTONE` | M-matrix monotone; falls back to TPFA if not achievable |
| `"monotone mfd hex"` | `MFD3D_HEXAHEDRA_MONOTONE` | Monotone variant specialized for hexahedra |
| `"optimized mfd"` | `MFD3D_OPTIMIZED` | Optimized inverse mass matrix |
| `"optimized mfd scaled"` | `MFD3D_OPTIMIZED_SCALED` | Optimized scaled |
| `"two point flux approximation"` | `MFD3D_TPFA` | Standard TPFA (reduces to finite volume on orthogonal meshes) |
| `"finite volume"` | `FV_TPFA` | Pure finite volume; changes vector space to cell+boundary_face |
| `"support operator"` | `MFD3D_SUPPORT_OPERATOR` | Support operator method |

All MFD methods delegate elemental matrix construction to Amanzi's `WhetStone::MFD3D_Diffusion` class, which is called from `CreateMFDmassMatrices()` (`src/operators/divgrad/MatrixMFD.cc:146`).

When `method_ == FV_TPFA`, the vector space changes: faces are replaced by `boundary_face` entities, so `space_` only has `"cell"` and `"boundary_face"` components (`src/operators/divgrad/MatrixMFD.cc:116`).

## Key methods and call sequence

### 1. Assembly

```
CreateMFDmassMatrices(K)       -- elemental inverse mass matrices Mff_cells_
    |-- WhetStone::MFD3D_Diffusion::MassMatrixInverse*()   [Amanzi side]
CreateMFDstiffnessMatrices(Krel) -- scales Mff by upwinded Krel; builds Aff, Acf, Afc, Acc
CreateMFDrhsVectors()          -- zero-initializes elemental rhs vectors Ff_cells_, Fc_cells_
ApplyBoundaryConditions(...)   -- modifies elemental matrices for Dirichlet/Neumann BCs
SymbolicAssembleGlobalMatrices() -- allocates Epetra_FECrsMatrix Aff_, Sff_
```

`CreateMFDstiffnessMatrices` handles upwinded relative permeability `Krel` in four modes, depending on whether `Krel` lives on `"cell"`, `"face"`, both, or neither (`src/operators/divgrad/MatrixMFD.cc:261`). This is the integration point between the upwinding layer and the MFD operator.

### 2. Apply (matvec)

`MatrixMFD::Apply(X, Y)` performs the unassembled matvec by looping over owned cells and accumulating contributions to ghost face unknowns, then calling `GatherGhostedToMaster("face", Add)` (`src/operators/divgrad/MatrixMFD.cc:506`). The macro `APPLY_UNASSEMBLED 1` (`src/operators/divgrad/MatrixMFD.cc:22`) selects this path.

### 3. Inverse (Schur complement)

`MatrixMFD::ApplyInverse(X, Y)` uses a block elimination Schur complement approach (`src/operators/divgrad/MatrixMFD.cc:563`):

1. **Forward elimination:** `Tf = Xf - Afc * inv(Acc) * Xc`
2. **Schur solve:** `Sff * Yf = Tf`, where `Sff = Aff - Afc * inv(Acc) * Acf` (assembled in `AssembleSchur_()`)
3. **Backward substitution:** `Yc = inv(Acc) * (Xc - Acf * Yf)`

The Schur complement `Sff_` is stored as an `Epetra_FECrsMatrix` and a separate preconditioner is constructed from it.

### 4. Flux recovery

`DeriveFlux(solution, flux)` recovers normal face fluxes from the mixed solution `(p_c, lambda_f)` by applying the local stiffness matrix to pressure differences (`src/operators/divgrad/MatrixMFD.cc:675`). `DeriveCellVelocity(flux, velocity)` reconstructs a cell-centered Darcy velocity using `WhetStone::MFD3D_Diffusion::RecoverGradient_MassMatrix` (`src/operators/divgrad/MatrixMFD.cc:741`).

### 5. Consistent face constraints

`UpdateConsistentFaceConstraints(u)` and `UpdateConsistentFaceCorrection(u, Pu)` solve the bottom row of the block system (`Aff * lambda_f = rhs_f - Afc * p_c`) using a separate `"consistent face solver"` linear solver specified in the input deck (`src/operators/divgrad/MatrixMFD.cc:765`).

## Coupled surface extension: MatrixMFD_Coupled_Surf

`MatrixMFD_Coupled_Surf` (`src/operators/divgrad/MatrixMFD_Coupled_Surf.cc`) extends the base `MatrixMFD_Coupled` (Amanzi side) to incorporate surface flow operators into the coupled subsurface-surface block system. It is used by the coupled surface-subsurface flow MPC.

Architecture: the class holds two surface TPFA operators (`surface_A_`, `surface_B_`, each a `MatrixMFD_TPFA`), where the surface cells are embedded as faces in the subsurface mesh via Amanzi's `getEntityParent()` mapping. The Schur complement assembly (`AssembleSchur_()`) first calls the base class to handle the subsurface MFD blocks, then adds the surface TPFA contributions as 2x2 blocks at the face positions corresponding to surface cells (`src/operators/divgrad/MatrixMFD_Coupled_Surf.cc:143`).

The surface off-diagonal coupling coefficients `Ccc_surf_` and `Dcc_surf_` (representing cross-process fluxes, e.g., seepage between subsurface and overland flow) are set via `SetOffDiagonals()` (`src/operators/divgrad/MatrixMFD_Coupled_Surf.cc:52`).

The operator stores its global system as an `Epetra_FEVbrMatrix` (`P2f2f_`, `A2f2f_`) using 2x2 variable block rows, one block per face, to interleave the coupled (pressure, temperature or pressure, pressure) unknowns (`src/operators/divgrad/MatrixMFD_Coupled_Surf.cc:135`).

## Integration with upwinding

The upwinding layer feeds into `MatrixMFD` through `CreateMFDstiffnessMatrices(Krel)`. The `Krel` argument is a `CompositeVector` whose components may include `"face"` (for face-upwinded coefficients from `UpwindTotalFlux`, etc.) or `"cell"` (for cell-centered coefficients from `UpwindCellCentered`). The stiffness matrix loop applies the appropriate weighting depending on which components are present (`src/operators/divgrad/MatrixMFD.cc:268`).

## Preconditioners supported

`MatrixMFD` creates two preconditioners from the `"preconditioner"` sublist in its parameter list (`src/operators/divgrad/MatrixMFD.cc:128`): `S_pc_` (applied to the Schur complement `Sff_`) and `Aff_pc_` (applied to `Aff_` when needed). Both use `AmanziPreconditioners::PreconditionerFactory` (Amanzi side).
