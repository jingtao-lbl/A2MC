# THE SURROGATE SUITE — the test files that exercise models/surrogate/ and its tools.
#
# WHY THIS FILE EXISTS. Three dev logs reported three different totals for "the surrogate tests"
# (230, 246, 254) because each ran its own ad-hoc recipe: one used `pytest -k surrogate`, which
# silently DESELECTS tests/test_kgml_emulator.py entirely -- neither the module name nor any test
# name contains the word, and that file holds every property the sequence-emulator work is about.
# Another used a `grep -l` over tests/*.py, whose match set grows with every new test file, so the
# number it printed could not be compared with the number printed a week earlier. A count nobody
# can reproduce is not evidence that a suite passed.
#
# HOW TO RUN IT:
#     ~/a2mc_env/bin/python -m pytest $(grep -v '^#' tests/SURROGATE_SUITE.txt) -q
#
# HOW IT STAYS TRUE: tests/test_surrogate_suite_registry.py fails when a test file imports the
# surrogate module or one of its tools and is not listed here, and when a listed file is missing.
# Adding a test file to the tree is therefore enough to be told to add it here.
